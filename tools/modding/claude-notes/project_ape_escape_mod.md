**GPU rule (learned 2026-10-01, cost a crash/freeze hunt):** never write GP0 from VBlank and never take packets from the game's packet buffer (0x800EC354) at DrawOTag. All mod drawing = packets in own psx_mod_alloc_gpu_dma_memory arena per frame buffer, linked into the OT at DrawOTag 0x80028CC0. Verify with debug cmd gpu_opcodes (no invalid opcodes) after a soak.

**SPU rule (learned 2026-10-01, caused savestate-load freezes):** game has SPU IRQ enabled with IRQ addr 0; never set transfer addr DA6 (or FIFO-write) at the IRQ address - restoring DA6=0 raised an SPU IRQ and wedged the game. Leave DA6 where our transfer ends.

**Savestate rule (2026-10-01):** anything a plugin swaps in guest RAM for part of a frame can be captured by a savestate and come back stuck; restore defensively at the next hook (Jake: jake_unstick; Spike mesh resident at 0x801030BC in all levels). Debug server can only LOAD states.
